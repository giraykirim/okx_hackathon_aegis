# AEGIS Person 1 Implementation Plan

**Goal:** Ship a tested, fail-closed FastAPI agent using actual OKX ATK observations, with honest integration evidence.

**Architecture:** Python owns the final deterministic gate and SQLite audit/idempotency journal. A fixed allowlist calls the official Node ATK CLI subprocess; typed LAN LAYA and discovered EVREN responses are advisory inputs. MOCK is explicit; missing integrations produce REVIEW/NO_TRADE. No live execution path exists.

**Tech stack:** Python 3.12, FastAPI/Pydantic, SQLite, httpx, pytest, official @okx_ai/okx-trade-cli 1.4.8.

Ownership: only backend/ and contracts/. No dashboard, training, deployment, wallet operations or fabricated identity verification. The brief supplies the design; proceed with implementation in this session.

1. **Policy and typed models** — create backend/aegis/models.py and policy.py; first add tests/test_policy.py covering stale/future data, duplicate intents, unknown/pending orders, invalid quantities, exposure, balances, non-CONTINUE LAYA, missing approval, and live rejection. Run pytest to see missing implementation fail, implement, rerun.
2. **Audit journal and runtime** — create store.py and agent.py; tests/test_agent.py proves unsafe scenarios never call execution, restart preserves unknown state, and mock outcomes never become VERIFIED. Use a single cycle lock and atomically journal PENDING before the external side effect.
3. **Bounded integrations** — integrations.py and atk.py with subprocess allowlist, isolated child credentials/config, hard --demo, regional site, strict response validation, model discovery and no arbitrary model tools. Test HTTP schemas, malicious model responses, timeout/ambiguous reconciliation, and adapter configuration.
4. **HTTP contract** — app.py with all shared v2 routes, bounded limits, authenticated control endpoints, SSE event replay, strict MOCK-only scenarios, identity NOT_TESTED until independently supplied/verified by Person 3. Generate contracts/openapi.yaml and document exact request/response semantics.
5. **Proof and handoff** — scripts/prove.py runs read-only ATK market observations and local autonomous MOCK/safety flows, saves redacted evidence; README and evidence matrix distinguish PASS/FAIL/NOT_TESTED. Run full pytest, ruff, contract drift check and real HTTP smoke tests before reporting.

Real integration blockers currently: no isolated OKX demo credentials, EVREN endpoint/account discovery, or LAN LAYA URL. Live exchange requests and wallets are outside the allowed build.
